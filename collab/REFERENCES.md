## ① 外側のマップ — 海沿いの丘の美術館（大塚国際美術館・鳴門の空撮）→ D `exterior_d.js`
**地形**: 森に覆われた岬の斜面。画面左上に海（ターコイズ〜青緑 #3fa7b0→沖 #2d7f97）、波打ち際は岩礁の海岸線（灰褐色の岩 #8c8273）。
森は濃い常緑広葉樹（#2f5a2a〜#4f7f3a、もこもこした樹冠が隙間なく続く）。
**建物（白い2棟＋1）**: 白いスタッコ/コンクリート #f2f1ec、窓は縦長で規則的、灰色の窓枠。
- 左棟: 約 50m×20m、高さ約 14m（3層）、長辺に **14ベイ** の縦長窓、屋上はフラット＋小さな塔屋。
- 右棟: 約 80m×22m の長い箱、**22ベイ**。奥に連なる約 35m×15m の小棟。屋上に設備の塔屋と天窓。
- 両棟は**屋上レベル**で中庭テラスにより連結。
**屋上芝生テラス**（2棟の間）: 約 45m×30m の長方形の芝生 #5a9a3c（刈り込みの縞）、周囲を白い舗石 #e3e1da の帯、
芝の端に石の縁取りと**段差**（数段の階段状テラス）。**白いパラソル＋テーブル 12組**（2列×6）。中央手前に**円形の花壇/噴水**。
**円形の段々庭園**（テラスの斜面下・軸線上）: 斜面に食い込む円形のサンクンガーデン。
- 中心に **楕円の浅い池（約 14m×8m、白い縁の水盤 #dfe7e6、水色 #8ccfd6）**、その外周を **リング状の水路（外径 約24m、水色 #4fa8b8、幅2m）**、
  その外側に白い円形の歩廊とベンチ。
- さらに外側に **同心円状の植栽段（3〜4段）**、各段の前面はコンクリート擁壁 #b5b2aa、段の上は低木の生垣。
- 左側に階段状の白い客席（扇形のひな壇）。
**擁壁**: 斜面全体に横長のコンクリート擁壁（2〜3段）。最下段にトンネル状の出入口。
**道路**: 画面下の斜面裾に2車線道路（アスファルト #55575a・白線）と街路樹。右上に駐車場と緑地、白い歩道。
**高架橋**: 右下を斜めに横切る **高速道路の高架（幅約12m、白灰色のコンクリート桁＋円柱橋脚 #c9c9c6、側面の防音壁）**。
**光**: 夏の真昼、高い太陽（北北西に短い影）、強いコントラスト、白い建物が明るく飛び気味。空は淡い青。

## ② システィーナ礼拝堂（大塚国際美術館の原寸再現）→ C `museum_c_sistine.js`（終幕）
**寸法**: 長さ 40.9m × 幅 13.4m × 高さ 20.7m。床から最上部まで壁面全てが絵画。
**天井**: やや扁平な **半円筒ヴォールト**。側面に **ルネット（半円の窓上アーチ）が片側6つ**、その間に **三角形のスパンドレル（ヴェーラ）片側5つ**。
- ヴォールト中央の背骨に **9面の物語画**（創世記: 光と闇の分離 → 天地創造 → 大地と水の分離 → アダムの創造 → エヴァの創造 → 原罪と楽園追放 → ノアの燔祭 → 大洪水 → ノアの泥酔）。
  大・小が交互。小パネルの四隅に **イニューディ（裸体の青年像）とブロンズ色のメダイヨン**。
- 描かれた建築（石色 #a89c8f の擬似コーニス・リブ）が画面を格子に区切る。
- **12人の預言者・巫女**が玉座に座る（長辺に5人ずつ、短辺に1人ずつ）。四隅に **ペンデンティブ（三角の隅画）4つ**。
- 素材: B が取得済み `site/assets/art/g1..g9`（9面）, `p_*.jpg`（預言者・巫女）, `w_judgement.jpg`（最後の審判）— 全て PD。
**祭壇壁**: **ミケランジェロ「最後の審判」が壁一面**（床上のダドから天井まで、建築的突出なし、青い空 #274272〜#1e3154）。
**側壁（3層）**: 上層=窓（片側6、アーチ形、ルネット直下）。中層=**モーセ伝・キリスト伝のフレスコ帯**（描かれたコリント式付柱で区切る）。
下層=**金銀の描かれたカーテン（ドレーパリー）**の帯。最下部は石張り #4e4641 の腰壁・扉口。
**照明**: 側壁の窓下に **3灯一組の上向きスポット**が並び、天井を暖色（3000〜3500K）で照らし上げる。床は暗色、中央に低い黒いベンチの列。

## ③ ウィーン美術史美術館（KHM）クーポラ・カフェ → C `museum_c_cupola.js`
**平面**: **八角形のロタンダ**（対辺 約22m）。8本の巨大な柱（各辺の角）が大アーチを支え、上部はクーポラ。
**中央の円形開口**: 床の中央に **直径 約8m（部屋幅の約1/3）の円形の吹き抜け**、下階が見える。縁は **赤いベルベット張りの円形バンケット/手すり #931314**（高さ約1m、厚み0.5m）。
**柱**: 磨かれた **暗緑〜黒の大理石 #1e2d24**（白い筋）と **赤褐色の斑岩 #5c2e2b** の組合せ、金の柱頭（コリント式）・柱礎。
**壁・アーチ**: 金箔 #d4af37 とスタッコの高浮彫、アーチの内側に彫刻と装飾画、ルネット状の高窓から光。
**床**: **幾何学象嵌の大理石**: クリーム #ece8dc 地に 黒 #1c1c1c と 赤褐 #7e3e34 で **八芒星・八角形・菱形の帯・放射状の帯**。開口を中心に放射状、外周は帯状のボーダー。
**家具**: 赤い椅子・小さな丸テーブル（白いクロス）多数、壁際に赤いベンチ、カウンター（金色の照明）。
**光**: クーポラの頂部（ランタン）からの拡散光＋暖色の卓上ランプ。全体に暖かいアンバー。

## ④ 国立新美術館（黒川紀章, 東京・六本木）アトリウム → A `lobby_a.js`
**ガラスのカーテンウォール**: 平面で **波打つ（正弦波状にうねる）** 巨大なガラス壁（高さ約 21.6m）。
外側に **水平のガラスルーバー（約0.5m間隔の帯、乳白〜淡緑 #d0e3e4）** が全面に走り、鉄骨フレーム #8a9597。うねりは全体で2〜3波。
**逆円錐**: 打放しコンクリート #c0c0c0 の **逆円錐（下が細く上が太い）** が2本、上に **円形のレストラン（上径 約18〜20m）**、円形の手すり。
円錐の表面は型枠の目地が水平に走る。もう一つの小さい逆円錐が奥に見える。
**床**: **斜めに張った中〜濃茶の木フローリング #5e4b3c**。
**家具・オブジェ**: 地上階にショップ — 円形の展示台（白/木 #d2b48c）、曲面の本棚。**木のブロックを積んだ松ぼっくり状の塔（高さ約4m）**。
**光**: ルーバー越しの非常に明るい拡散光（青白い昼光）、柔らかい長い影、全体に明るく軽い。

## 共通の質感メモ（A）

- 金は metalness 1, roughness 0.25〜0.4, color #d4af37〜#c9a25e。大理石は clearcoat で「磨き」を出す。
