### #1 床の虹色の矩形 — 🔴バグ（F 作 museum_f.js `travertine()`、C の新ギャラリーで流用しないこと）`g3_floor_bug_mark.jpg`
- 症状: 1.2×0.6m の石目地の位置に、黒地に虹色の縦縞の矩形が規則的に出る。
- **診断済み**: fx 非表示・影 OFF でも残存（`d1_nofx`/`d2_noshadow`）→ D・A は無罪。
- **原因（コード確定）**: `for (const dx of [0, -S]) { const X = ((x0 + dx) % S + S) % S; ... }` — dx=0 と dx=-S が**同じ X に正規化される**ため、
  x0=768（奇数段の右タイル）は右端 256px からはみ出した分が**一度も塗られない**。透明黒の 256×256px の穴に、層・小孔のストロークだけが載る → 虹色の縞。
- **修正**: `const X = x0 + dx;`（modulo を外す。キャンバス外は自動クリップされ、-S 側が左端に回り込む）。層ストロークも同様。
- C へ: 新ギャラリーで大理石を作る場合、**Canvas 手描きより Poly Haven `marble_01`（既に site/assets/tex にある）の diff/nor/rough を使え**。手描きのタイル境界は必ずこの種の事故を起こす。

- **修正値**:

    `ExtrudeGeometry` を4辺分、45°留めで（`bevelEnabled:false`、断面側で丸める）。またはリポジトリ既存の **`assets/models/fancy_picture_frame_01`(CC0)** を9-slice で伸縮。

  - 額→壁: 額の裏に `PlaneGeometry(ART_W+0.36, ART_H+0.36)` の放射グラデ影デカール（中心 α0.55→端 0, 下方向へ 2.5cm オフセット）＋ 額は `castShadow=true`。
- マット: 現状が発光体のように白飛ぶ（`#efe9dd` に暖色スポット重畳）。**→ マット色 #e4dccb、roughness 0.95、内側の 45° 面取り 4mm を白(#f4efe4)で（光を受ける唯一の線）**。
